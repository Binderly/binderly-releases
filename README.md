# Binderly - download

Questo repository contiene gli installatori ufficiali di **Binderly** e i file usati dagli aggiornamenti automatici dell'app.

- Scarica l'ultima versione dalla pagina [Releases](../../releases/latest).
- L'app installata controlla da sola la presenza di nuove versioni.

Il codice sorgente e' proprietario e non e' pubblico. Tutti i diritti riservati.

Binderly e' un progetto non ufficiale, non affiliato ne' approvato dai publisher dei giochi di carte. Nomi, immagini e simboli appartengono ai rispettivi proprietari.
